Focus Terminal for macOS

Support

Focus Terminal turns a focus session into a flight: book a route, print a boarding pass, watch the route unfold, and land with a stamp in your passport.

Need a hand? Email waaridh@icloud.com. Please include your Focus Terminal version and macOS version (Settings › Data & Licenses shows the version; the Send Feedback button pre-fills both).

Getting started

First launch
Focus Terminal opens with a short pre-flight briefing and asks you to set a home airport. Every flight departs from there. You can change it later in Settings.
Booking a flight (starting a focus session)
From the departures board, choose Book a Flight (or press ⌘N). Pick a destination and fare — the flight’s duration is your focus time. Confirm to print a boarding pass, then board to begin.
In the air
The in-flight screen shows a live map (Flight Deck) and a Cabin View scene. Turn on Pure Mode from the menu bar for a minimal view. The menu-bar plane shows your live status even when the window is closed.
Landing
When the timer completes you land, collect a passport stamp, and can review the flight in your Log, Passport, and Stats. You can also divert (end early) from the in-flight screen or the menu bar.

Features & settings

Cabin Mode (no-fly list)
In Settings, add apps that pull you off task. If you linger on one mid-flight, Focus Terminal flips on the “seatbelt sign” with a turbulence nudge. It never closes or blocks other apps — it only reminds you.
Notifications
Focus Terminal uses local notifications for turbulence reminders and landing alerts. It asks for permission when you board your first flight. Grant permission when macOS asks, or later in System Settings › Notifications › Focus Terminal.
Cabin audio
An optional, gently synthesized cabin hum that follows the phases of flight. It’s off by default and never uses your microphone. Enable, mute, and set the volume in Settings › Cabin Audio.
Focus Shortcut
Optionally enter the exact name of a Shortcut you built in the Shortcuts app (for example, one that toggles Do Not Disturb). Focus Terminal runs it at boarding and again at landing. Leave it blank to skip.
Export
You can save your arrival card as an image using the standard macOS save panel. Files are written only where you choose.
Changing or resetting your home airport
Settings › Home Airport › Change… returns you to the airport picker. (You can’t change it mid-flight.)
Deleting all Focus Terminal data
Quit Focus Terminal, then in Finder choose Go › Go to Folder… and enter ~/Library/Containers/com.waaridh.FocusTerminal. Move that folder to the Trash and empty the Trash. Deleting only the app may leave its local container in place. Backups such as Time Machine may retain older copies according to your backup settings.

Troubleshooting

The map is blank or won’t load
The map uses Apple Maps and needs internet access to fetch tiles. Check your connection; if you use a firewall or content blocker, allow Focus Terminal network access. Map data is served by Apple.
I’m not getting notifications
Open System Settings › Notifications › Focus Terminal and make sure notifications are allowed. If you use a Focus, allow Focus Terminal through it so flight updates still come through.
“Send Feedback” does nothing / no email app
The button opens your default email app. If none is set, use Copy Email Address in Settings and email waaridh@icloud.com from any device.
My Focus Shortcut didn’t run
The name in Settings must match a Shortcut in the Shortcuts app exactly. Make sure the Shortcut exists and runs on its own, then re-enter the name.

Requirements

  • macOS 14 (Sonoma) or later.
  • Apple silicon or Intel Mac.
  • The core app works offline. Internet access is needed to load map tiles and to send feedback through your email provider.
